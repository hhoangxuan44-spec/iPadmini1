# 光影月历 · iPad mini 1 桌面摆件

把老 iPad mini 1（iOS 9.3.5）变成一块会自己换画的「壁纸月历」：放在桌上横屏立着，不用去碰它。

- **壁纸轮播**：755 张精选图片，每 5 分钟随机换一张（交叉淡入淡出 + 缓慢推拉）
  - 自然：雪山、冰川、荒漠、盐原、湖泊、极光、火山、星空、野生动物
  - 中国风光：张家界、桂林、梯田、大雁塔、长城、悬空寺、九寨沟、梅里雪山、维多利亚港……
  - 城市与建筑：布拉格、布达佩斯、苏黎世、布鲁日、阿马尔菲、纽约、京都、教堂与古城
  - 东方绘画：北斋《富岳三十六景》（含《神奈川冲浪里》《凯风快晴》）、广重《东海道五十三次》《名所江户百景》、
    郭熙《早春图》、李唐《万壑松风图》、赵孟頫《鹊华秋色图》、马麟、董其昌、石涛、八大山人、郎世宁
  - 西方绘画：莫奈、凡·高、透纳、维米尔、希施金、列维坦、比尔施塔特、艾瓦佐夫斯基、弗里德里希
- **每张图配文字**：中文标题、地点或作者年代，以及两三句描述（`build/catalog.py`，逐张手写）
- **每日一言**：每天一句经典（《论语》《老子》《庄子》《孟子》《荀子》、唐宋名句、先哲箴言），注明出处
- **古诗词**：124 张图配了一句意境相合的古诗词（如广重的「海日生残夜，江春入旧年」、银河配「迢迢牵牛星，皎皎河汉女」）
- **应景选图**：仍是随机轮播，但会按时节提高相应图片出现的机会——冬天多雪景、夜里多星空与月色、清晨多日出、
  中秋与元宵多月亮、春节多喜庆暖色、七夕多银河、重阳多登高群山
- **日历随图片变化**：构建时分析每张图——
  - 颜色：日历的点缀色、色带颜色取自这张图
  - 位置：自动放在画面最空的区域（天空、水面等），不挡主体
  - 形状：八种风格按图分配——极简（文字直接压在照片上）、玻璃（磨砂卡片）、杂志（整列侧栏 + 超大月份数字）、
    色带（底部整条色块）、海报（超大日期数字）、宣纸（纸张卡片，东方绘画加朱红印章）、
    画廊装裱（名画按原比例完整挂在模糊墙面上，卡纸 + 画框 + 美术馆说明牌）、竖排诗笺（古诗竖排书写）
- **月历**：本月日历，每天下面标农历，节日与节气用点缀色标出；小字时钟与今日日期
- **操作**（平时不用碰）：轻点换下一张；左右滑动看上个月 / 下个月，1 分钟后自动回到本月
- 夜间（23:00–7:00）自动调暗；每天凌晨 4 点自动刷新一次，防止长时间运行后卡顿

## 兼容性

- 代码全部是 ES5，CSS 动画全部带 `-webkit-` 前缀，不用 CSS 变量、grid、`backdrop-filter`
- 检测到 iOS 10 及以下的老设备（iPad mini 1 等）会自动进入省电模式：关闭推拉动画，只加载 1280 像素的图片
- 玻璃模糊用构建时生成的小尺寸模糊图实现，不消耗设备性能
- 数字字体内置 Inter Display 子集（SIL OFL 授权，见 `fonts/OFL.txt`），在 iPad 和安卓上显示一致
- 以 1024×768 横屏为准设计；竖屏和手机也能正常显示

## 发布到网上（GitHub Pages）

仓库里的 GitHub Actions（`.github/workflows/pages.yml`）会在每次推送时：下载图片 → 生成各尺寸 → 发布到 GitHub Pages。

第一次需要在 GitHub 上打开一次 Pages：

1. 进入仓库 **Settings → Pages**
2. **Source** 选择 **GitHub Actions**
3. 到 **Actions** 页面重新运行一次「构建并发布月历」

完成后网址是 `https://<你的用户名>.github.io/iPadmini1/`。

> 私有仓库在免费账户下不能开 GitHub Pages，需要把仓库设为公开，或升级账户。

## 在 iPad 上安装成「App」

1. iPad 上用 Safari 打开网址
2. 点分享按钮 → **添加到主屏幕**
3. 从主屏幕图标打开，就是全屏、无地址栏的月历
4. **设置 → 通用 → 自动锁定 → 永不**，让屏幕一直亮着
5. （可选）**设置 → 通用 → 辅助功能 → 引导式访问**：打开后三击 Home 键锁定在月历里

## 离线使用（断网也能运行）

网站带有「离线图包」：第一次联网打开时，网页本身和约 22MB 的精选图片（约 60–80 张，各题材、各风格都有）会存到 iPad 本地。之后：

- **有网**：全部 755 张图轮播，和平时一样
- **断网**：自动只轮播离线图包里的图；时钟、月历、农历、诗词、每日一言全部照常
- **网站更新**：iPad 联网时在后台下载新版本，下载完自动刷新

第一次设置：

1. 连上 Wi-Fi，用 Safari 打开网址，**添加到主屏幕**
2. **从主屏幕图标打开**（主屏幕 App 和 Safari 的缓存是分开的，一定要在这里下载）
3. 保持屏幕常亮几分钟，屏幕上方会显示「离线图包下载中 x/y」，直到出现「离线图包已就绪」
4. 之后断开 Wi-Fi 也能正常显示

技术说明：使用 HTML5 Application Cache（`offline.appcache`，构建时自动生成）。iOS 9 的 Safari 支持它；新版浏览器已经移除了这项技术，但在新设备上网页仍可正常在线使用。离线图包的大小可以用 `python3 build/build_site.py --offline-mb 30` 调整。

## 安卓平板 App（壁纸 + 桌面组件）

安卓上的做法是分层：**下层是壁纸，只放图片；上层是桌面组件，日历样式随每张图变化**。

- **动态壁纸**：每 5 分钟换一张，交叉淡入淡出；应景选图（季节、早晚、节日）；夜间自动调暗；画作按原比例挂在模糊的墙面上，画框让到日历组件的另一侧
- **月历组件**：时钟、日期、农历、每日一言和本月日历，用 Canvas 原生绘制，八种风格（极简、玻璃、杂志、色带、海报、宣纸、画廊、诗笺）随当前壁纸切换；组件拖多大就排多大——竖长的上下排，扁长的左右排；点一下组件换下一张壁纸
- **画意组件**：这张图的标题、出处、诗句和几句描述，风格与月历一致
- **日历位置**：在 App 里选「日历组件放在桌面的哪里」，壁纸会优先挑这个位置画面安静的图片，文字深浅也按这里的明暗决定
- **全屏摆件模式 / 屏幕保护程序**：和 iPad 上一样的网页版，全屏常亮，不需要桌面组件
- **离线**：连 Wi-Fi 打开 App 会把全部图片存到本地，之后断网也能完整轮播；网站更新后自动用上新内容，不用重装

安装：平板浏览器打开 `https://<你的用户名>.github.io/iPadmini1/guangying.apk` 下载并安装（需要允许「安装未知应用」），然后在 App 里依次：设为桌面动态壁纸 → 添加月历组件 → 添加画意组件 → 选择日历位置。

APK 由 Actions 在每次发布时自动打包（`android/`，Java，无第三方依赖）。签名证书 `android/app/guangying.keystore` 固定放在仓库里，保证新版本能直接覆盖安装；它只用于自己侧载安装，不要用于上架应用商店。

组件的绘制代码在 `android/app/src/main/java/io/github/guangying/render/`。`android/tools/render-test/` 是一套在电脑上预览组件的测试（Robolectric，不需要手机）：`android/tools/render-test/run.sh WidgetRenderTest`，生成的各种风格、各种尺寸的组件图片在 `/tmp/render-out`。

## 操作

| 操作 | 效果 |
| --- | --- |
| 轻点屏幕 | 换下一张壁纸 |
| 左滑 / 右滑 | 看下个月 / 上个月（1 分钟后自动回到本月） |
| 电脑：空格 / 回车 / 点击 | 换下一张 |
| 电脑：← → | 切换月份 |

调试用网址参数：`?photo=12` 打开第 12 张图，`?night=0` 关闭夜间调暗，`?lite=1` 模拟老设备省电模式。

## 设置

编辑 `js/config.js`：切换间隔、回到本月的时间、推拉动画开关、24 小时制、夜间调暗时段。

## 加入自己的照片

把照片放进仓库根目录的 `photos/` 文件夹（jpg / png），推送后会自动处理并加入壁纸轮换。

## 本地预览

```bash
pip install Pillow
python3 build/build_site.py            # 需要能访问 commons.wikimedia.org
# 或者离线：python3 build/build_site.py --fake 12   （生成测试图）
cd dist && python3 -m http.server 8000
```

然后浏览器打开 `http://localhost:8000`。同一局域网里的 iPad 也可以访问 `http://电脑IP:8000`。

## 图库与文字

- 图库定义在 `build/catalog.py`：Commons 文件名、类型、中文标题、副标题、描述，以及 `POEMS`（诗句）和 `TAGS`（季节 / 时段 / 主题标签）。增删图片改这个文件即可
- 想挑新图：在 Actions 里手动运行「列出候选图片」，日志里会列出 300 多张 Commons 精选图片及其原始说明
- 所有图片来自 [Wikimedia Commons](https://commons.wikimedia.org/)，均为公有领域或 Creative Commons 等自由授权，每张图的说明下方都会署名作者与授权协议

## 文件结构

```
index.html               页面
css/wall.css             样式（八种日历风格、材质层、光影、翻页与动效、竖屏适配）
js/wall.js               主程序（轮播、月历、手势、老设备省电模式）
js/lunar.js              农历、节气、节日
js/mottos.js             每日一言
js/config.js             设置
fonts/                   Inter Display 数字字体子集
build/catalog.py         精选图库与中文描述
build/theme.py           每张图的日历主题分析（颜色、位置、风格）
build/build_site.py      下载图片、生成多尺寸与模糊图、输出 dist/
build/list_candidates.py 列出候选图片（供挑选）
build/make_icons.py      生成主屏幕图标
android/                 安卓 App：动态壁纸、屏保、全屏摆件、图片本地缓存
.github/workflows/       自动构建与发布
```
