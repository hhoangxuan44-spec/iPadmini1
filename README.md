# 光影月历 · iPad mini 1 桌面摆件

把老 iPad mini 1（iOS 9.3.5）变成一块会自己换画的「壁纸月历」：放在桌上横屏立着，不用去碰它。

- **壁纸轮播**：115 张精选图片，每 5 分钟随机换一张（交叉淡入淡出 + 缓慢推拉）
  - 约 72%：雪山、冰川、荒漠、盐原、湖泊、极光、火山、星空、野生动物
  - 约 28%：歌川广重《东海道五十三次》、葛饰北斋、清代扇面山水、莫奈、凡·高、艾瓦佐夫斯基、弗里德里希
- **每张图配文字**：中文标题、地点或作者年代，以及两三句描述（`build/catalog.py`，逐张手写）
- **古诗词**：75 张图配了一句意境相合的古诗词（如广重的「海日生残夜，江春入旧年」、银河配「迢迢牵牛星，皎皎河汉女」）
- **应景选图**：仍是随机轮播，但会按时节提高相应图片出现的机会——冬天多雪景、夜里多星空与月色、清晨多日出、
  中秋与元宵多月亮、春节多喜庆暖色、七夕多银河、重阳多登高群山
- **日历随图片变化**：构建时分析每张图——
  - 颜色：日历的点缀色、色带颜色取自这张图
  - 位置：自动放在画面最空的区域（天空、水面等），不挡主体
  - 形状：五种风格按图分配——极简（文字直接压在照片上）、玻璃（磨砂卡片）、杂志（整列侧栏 + 超大月份数字）、色带（底部整条色块）、宣纸（名画用纸张卡片，东方绘画加朱红印章）
- **月历**：本月日历，每天下面标农历，节日与节气用点缀色标出；小字时钟与今日日期
- **操作**（平时不用碰）：轻点换下一张；左右滑动看上个月 / 下个月，1 分钟后自动回到本月
- 夜间（23:00–7:00）自动调暗；每天凌晨 4 点自动刷新一次，防止长时间运行后卡顿

## 兼容性

- 代码全部是 ES5，CSS 动画全部带 `-webkit-` 前缀，不用 CSS 变量、grid、`backdrop-filter`
- 检测到 iOS 10 及以下的老设备（iPad mini 1 等）会自动进入省电模式：关闭推拉动画，只加载 1280 像素的图片
- 玻璃模糊用构建时生成的小尺寸模糊图实现，不消耗设备性能
- 数字字体内置 Inter Display 子集（SIL OFL 授权，见 `fonts/OFL.txt`），在 iPad 和安卓上显示一致
- 以 1024×768 横屏为准设计；竖屏和手机也能正常显示

## 发布到网上（GitHub Pages）

仓库里的 GitHub Actions（`.github/workflows/pages.yml`）会在每次推送时：下载图片 → 生成各尺寸 → 发布到 GitHub Pages。

第一次需要在 GitHub 上打开一次 Pages：

1. 进入仓库 **Settings → Pages**
2. **Source** 选择 **GitHub Actions**
3. 到 **Actions** 页面重新运行一次「构建并发布月历」

完成后网址是 `https://<你的用户名>.github.io/iPadmini1/`。

> 私有仓库在免费账户下不能开 GitHub Pages，需要把仓库设为公开，或升级账户。

## 在 iPad 上安装成「App」

1. iPad 上用 Safari 打开网址
2. 点分享按钮 → **添加到主屏幕**
3. 从主屏幕图标打开，就是全屏、无地址栏的月历
4. **设置 → 通用 → 自动锁定 → 永不**，让屏幕一直亮着
5. （可选）**设置 → 通用 → 辅助功能 → 引导式访问**：打开后三击 Home 键锁定在月历里

## 操作

| 操作 | 效果 |
| --- | --- |
| 轻点屏幕 | 换下一张壁纸 |
| 左滑 / 右滑 | 看下个月 / 上个月（1 分钟后自动回到本月） |
| 电脑：空格 / 回车 / 点击 | 换下一张 |
| 电脑：← → | 切换月份 |

调试用网址参数：`?photo=12` 打开第 12 张图，`?night=0` 关闭夜间调暗，`?lite=1` 模拟老设备省电模式。

## 设置

编辑 `js/config.js`：切换间隔、回到本月的时间、推拉动画开关、24 小时制、夜间调暗时段。

## 加入自己的照片

把照片放进仓库根目录的 `photos/` 文件夹（jpg / png），推送后会自动处理并加入壁纸轮换。

## 本地预览

```bash
pip install Pillow
python3 build/build_site.py            # 需要能访问 commons.wikimedia.org
# 或者离线：python3 build/build_site.py --fake 12   （生成测试图）
cd dist && python3 -m http.server 8000
```

然后浏览器打开 `http://localhost:8000`。同一局域网里的 iPad 也可以访问 `http://电脑IP:8000`。

## 图库与文字

- 图库定义在 `build/catalog.py`：Commons 文件名、类型、中文标题、副标题、描述，以及 `POEMS`（诗句）和 `TAGS`（季节 / 时段 / 主题标签）。增删图片改这个文件即可
- 想挑新图：在 Actions 里手动运行「列出候选图片」，日志里会列出 300 多张 Commons 精选图片及其原始说明
- 所有图片来自 [Wikimedia Commons](https://commons.wikimedia.org/)，均为公有领域或 Creative Commons 等自由授权，每张图的说明下方都会署名作者与授权协议

## 文件结构

```
index.html               页面
css/wall.css             样式（五种日历风格、玻璃、推拉动画、竖屏适配）
js/wall.js               主程序（轮播、月历、手势、老设备省电模式）
js/lunar.js              农历、节气、节日
js/config.js             设置
fonts/                   Inter Display 数字字体子集
build/catalog.py         精选图库与中文描述
build/theme.py           每张图的日历主题分析（颜色、位置、风格）
build/build_site.py      下载图片、生成多尺寸与模糊图、输出 dist/
build/list_candidates.py 列出候选图片（供挑选）
build/make_icons.py      生成主屏幕图标
.github/workflows/       自动构建与发布
```
